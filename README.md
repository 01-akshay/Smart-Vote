# Smart-Vote

> A secure and transparent digital voting system designed to ensure fair, accurate, and efficient elections.

## Overview

Smart-Vote is an AI-powered digital voting platform developed to improve election transparency, security, and efficiency.

The system combines biometric voter verification, AI-based fraud detection, real-time monitoring, and secure vote management to create a reliable digital election environment.

This project was developed by **Team Neo**.

---

## Features

- Biometric voter verification
- AI-based fraud detection
- One person, one vote
- Real-time election monitoring
- Live result tracking
- Election history management
- Audit and security logs
- Party and voter management
- Secure vote recording
- JSON and CSV data export

## Installation

Install the required packages:

```bash
npm install
```

Run the backend server:

```bash
npm run server
```

Run the React application:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
